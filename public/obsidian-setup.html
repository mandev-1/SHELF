Obsidian connection setup

ShELF can send your Pillar todo log (task notes, completions, comments) to a note in Obsidian. This guide walks you through the setup.

1. Install the Local REST API plugin in Obsidian

  1. Open Obsidian and go to Settings → Community plugins.
  2. If needed, turn Restricted mode off and click Browse.
  3. Search for Local REST API (by coddingtonbear) and install it.
  4. Enable the plugin, then open Settings → Local REST API.

2. Enable and configure the API

  • Turn Enable Local REST API on.
  • Note the Port (default 27124) and whether you use HTTPS or HTTP.
  • Set or copy the API Key — you’ll paste this into ShELF.

If you use HTTPS, you may need to trust the plugin’s certificate in your browser (or use HTTP for local use).

3. Create a note (or folder) for logs

Decide where ShELF should append log lines:

  • Single note — e.g. ShELF/todo-log.md. All logs go to this file.
  • Daily notes — enable “Use daily note” in ShELF and set a folder path (e.g. Daily or ShELF/daily). ShELF will append to YYYY-MM-DD.md inside that folder.

Create the note or folder in your vault if it doesn’t exist; the API can create the file on first write.

4. Fill in ShELF settings

In ShELF, open Settings (gear icon) and expand Obsidian log. Then:

  1. Enable todo log to Obsidian — turn this on.
  2. Base URL — http://127.0.0.1:27124 (or https://127.0.0.1:27124 if you use HTTPS and the port you set in Obsidian).
  3. API Key — paste the key from Obsidian’s Local REST API settings.
  4. Note path — e.g. ShELF/todo-log.md for a single note, or the folder path (e.g. Daily) if you use daily notes.

Click Test connection to send a test line to Obsidian. If it works, you’re done.

5. Optional: open the log from ShELF

Use Open task log in Obsidian in settings to open the current log note in Obsidian. In Obsidian you can then use “Reveal in folder” to open the directory that contains the markdown files.
