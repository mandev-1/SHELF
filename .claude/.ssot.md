## 1. Surfaces (high-level)

Top-level chrome is a left **Pillar** sidebar + a `.main` column with a `.topbar` (greeting + search + `.nav`) and a scrolling `.canvas`. Tabs in `.nav`:

- **Shelf** — `PromptCard` on top, then `.grid-bar` (folder count + "New folder"), then the bookmark `.grid` of `FolderCard`s plus a `GoalCard` (drag/sort via `useSortable` + FLIP).
- **Visual Flow** — node-graph view (nodes/edges/sectors/grazeland); prototype shows an empty-state placeholder, real impl lives in `src/components/VisualFlowPanel.tsx`.
- **Strategie** — finance dashboard: KPI strip → 5-year projection chart → ladder (order-of-operations) → "Spending by week" → cashflow ring + Allocation bar + Pots + Life pillars. Modal: `StatementEditor` (the editable monthly income + dated spending book).
- **Hopper** — single buy-line: a "chute" with a queue of `puck`s falling toward a `tray` ("Next to buy"). Toss in, bump, skip, bought.
- **Budget** — shared holiday/expense splitter (handoff 006). Monthly dashboard: members, expenses, settle-up, split-basis; `BudgetPanel.tsx` + `budget.css`. Local-first blob `shelf-budget`; also ships as a standalone hosted app (`apps/budget`, three-tier — see [[2026-06-21-budget-three-tier]]). Add-Expense modal is 1:1 from the handoff with receipt OCR.
- **LLM Console overlay** (extension): top-bar + Prompt Library sidebar injected over a navigated tab — never an iframe.
- **Pillar** (sidebar, always visible): shelf greeting + `.todo-add` + `.todo-list` with focus pins + prompt count + completion log.

Global UI shells (only in the proto): `.bg-diffuse` ambient radial-gradient glow behind everything, animated by `@keyframes drift` (34s), and a floating `TweaksPanel` (theme/identity/accent/currency/surface/density/radius). `⌘K` focuses the search.

## 4. Layout primitives

### Shell
`.bg-diffuse` (fixed, inset -15%, blurred radial gradients of `--accent`, `--hue-blue`, `--hue-purple`, animated by `drift`). `.shell` is a flex row containing `Pillar` + `.main`. `.main` stacks a sticky `.topbar` and a scrolling `.canvas` (padding `26px 32px 60px`). `.canvas-inner` holds the active tab.

### `.card`
Background `var(--surface)`, border `1px solid var(--line)`, radius `var(--r-card)`, shadow `var(--sh-2)`, padding `var(--pad)`. `.card-head` is flex row (flex-start, gap 14, margin-bottom 16). `.card-eyebrow` and `.card-title` as above.

### `.seg` segmented control
`display: inline-flex; padding: 3px; gap: 2px; background: var(--inset); border: 1px solid var(--line); border-radius: 10px;`. `.seg-btn` is unstyled until hover (gains `--fg-2`) and `.on` (gains `--surface-2` background + `--fg` + `var(--sh-1)`).

### `.ghost-btn`
Surface button, `1px solid var(--line)`, `--muted` text, gap 6, padding/radius matching mini controls; hover lifts to `--surface-2` + `--line-strong` + `--fg`. SVG icons sized 14×14. `.ghost-btn.ok` variant: accent-tinted border + `--accent-bright` text.

### `.mini-ghost`
12px / 600 / `--fg-2` on `--surface-2`, border `--line`, radius 8, padding 6×10. SVG 13×13. Hover → `--surface-3` + `--line-strong`.

### `.nav-btn`
Top-bar tabs. Default: `--surface`, border `--line`, `--muted`. `.nav-btn--on` swaps to accent-tinted surface + `--accent-bright` text. On light themes the "on" state uses `--accent-deep`.

### 12-col grid
`.strat-grid { display: grid; grid-template-columns: repeat(12, 1fr); gap: 14px; align-items: start; }` with `.span-8` and `.span-4`. Used inside the Strategie surface to lay out KPI row, projection (8) + sidebar (4), etc.

### Modal / backdrop pattern
Two backdrop families share a recipe:
- `.se-backdrop` / `.ld-backdrop`: `position: fixed; inset: 0; z-index: 200+; display: grid; place-items: center; padding: 28px; background: color-mix(in srgb, var(--bg-grad-b) 55%, rgba(0,0,0,0.6)); backdrop-filter: blur(8px) saturate(120%); animation: se-fade 0.16s ease;`
- `.se-modal` / `.ld-modal`: `background: var(--panel); border: 1px solid var(--line-strong); border-radius: calc(var(--r-card) + 6px); box-shadow: var(--sh-pop); animation: se-rise 0.22s cubic-bezier(0.2,0.8,0.3,1);` — width capped (`min(900px, 100%)` for statement, `min(560px, 100%)` for ladder), `max-height: calc(100vh - 56px)`, internal flex column with scroll.
- Outside-click on backdrop closes. `Escape` closes; if a sub-popover is open (e.g. month picker), first Escape closes the popover, second Escape closes the modal.

### `.toast`
Small `--accent`-tinted pill that briefly appears top-right with a check icon.

## 5. Per-surface anatomy

### 5.1 Shelf (BookmarkGrid)

Wrapper: `.canvas-inner > [React.Fragment]` containing:
- `<PromptCard data={D} onToast={…} />` — top promo / library callout.
- `.grid-bar` with `.grid-hint` ("N folders · drag to rearrange") and `.grid-actions` containing a `ghost-btn` "New folder".
- `.grid` — flex/grid container, drag-sorted via `useSortable` (FLIP animation). Children: many `<FolderCard>` + one `<GoalCard>`.

**FolderCard** (`.folder`): per-folder `--hue` driven by `folder.hue` (one of `var(--hue-*)`). Children:
- `.folder-head` (cursor grab; grip dots `.folder-grip span`; title `.folder-title`; count `.folder-count`; pseudo `::before` for the hue dot).
- `.folder-body` containing `.bm` (small bookmark row) and `.bm-big` (large card) entries; hover dims siblings to 0.45 and full-opacity on target. `{ sep: true }` items render a separator.

**GoalCard** (`.goal`): card with `.goal-eyebrow`, `.goal-title`, progress `.goal-bar > .goal-fill` (hue mix `--hue-blue`), `.goal-foot` with `.goal-pct` and `.goal-cta` ghost button.

Drag/click/keyboard: drag to reorder folders; click any `.bm` opens its URL; `⌘K` (or `Ctrl-K`) focuses search.

Reads/writes: each folder `{ id, title, hue, dot, bookmarks: [{title,host,url} | {sep:true} | {big,title,host,url,initials,color}] }`.

### 5.3 Visual Flow

Prototype only ships a placeholder `.empty-state` ("A node-graph view of your bookmarks lives here in the full app."). **"Doing now" drawer** (handoff 010, 2026-06-22) — a bottom pull-up pipeline drawer mounted inside the `.visual-flow-canvas` container (which gained `overflow-hidden`; the drawer + handle are `position:absolute`). Holds **1 active task + up to 6 "up next" queue cards** with marching arrows between them; toggle handle shows a count badge. Per-task plane **dot/label** are dynamic (main=accent, grazeland=amber, bin=sky, custom=its colour). Add/Remove via the node right-click menu (first item); **Done & next** marks the active task complete on whichever plane it lives; **Jump** switches plane if needed then `panToNode`. Component + controlled hook in `src/components/VisualFlow/DoingNow.tsx`; styles `src/components/VisualFlow/doing-now.css` (verbatim handoff CSS, `.nf-doing*`). Persisted as an ordered id list at `visualFlow.doingNow {pipeline, open}` — backup-covered by construction. See [[2026-06-22-doing-now-drawer]].

**Blockers** (handoff 011, `3d7e57f`+) — time-block hazard nodes that live in **two places at once**: a `.nf-blocker` node rendered on the canvas via React Flow's `ViewportPortal` (positioned by flow x/y, draggable, pending→active phases) **and** a Doing-now queue item that auto-promotes to the active slot + toasts once when its window opens. Created from a **right-click menu on the Doing-now drawer** ("⛔ Add blocker" — *not* the canvas pane menu, moved there 2026-06-23); right-click a blocker node → its own menu (Edit time… / Clear). **"Edit task" editor** (handoff 011) — a full-screen two-column editor that overlays *only the canvas* (`.nf-te`, `position:absolute; inset:0`, NOT fixed/portaled/centered — corners clip to the canvas radius), opened from a Doing-now task item's Edit button. ### Semantics

- **USD-base storage.** Every amount in `book` is integer USD. `cur = window.CURRENCIES[currency]`; `shown(base) = round(base * cur.rate)`, `toBase(shown) = round(shown / cur.rate)`. Display uses `Intl.NumberFormat(cur.locale, { style:'currency', currency:cur.code, maximumFractionDigits:0 })`. Currency prefix symbol (`.se-cur`): `Kč | € | $`.
- **Income is monthly carry-forward.** Income rows `{ id, label, amt, kind }` are not dated. Advancing months via the next-arrow (or "Start <month>") calls `cloneMonth(prevMonth, nextKey)`: income copied verbatim; expenses get a new `date` preserving day-of-month, clamped to the new month's length.
- **Expenses are dated.** Shape `{ id, label, cat, amt, date }` where `date = "YYYY-MM-DD"`. `window.weekOfDate(monthKey, date)` bins each into a week. Rows are sorted chronologically.
- **Week strip math.** `window.monthWeeks(key)` produces Monday-aligned weeks clamped to the month — `[{ idx, startDay, endDay, label: "W{idx}", range: "MMM d–e" }]`. The first "week" begins on day 1 regardless of weekday, ending at the next Sunday (or month-end). Per-week totals from `weekOfDate==idx` sums. Strip bar height = `round(total / maxWeek * 100)%`. Clicking a bar toggles to that week in "By week" mode; clicking the active bar returns to month mode. Selected week gets `.se-wk.on`.
- **Whole month / By week toggle** (`.seg` inside `.se-gran`): `gran` is `"month" | "week"`. In `"week"` mode, the spending list filters and the column hint shows `{activeWeek.label} · {activeWeek.range}`; in `"month"` mode the hint is `dated`. New-expense button reads "Add expense in W{n}" while in week mode.
- **Income/spending column heads.** `.se-pill.se-pill--in` is a 24×24 7px-radius square tinted with `color-mix(--accent 20%, transparent)` containing an `in` arrow; `.se-pill--out` is `--hue-rose` tinted with an `out` arrow. `.se-col-sum` is mono, 15px / 500, tabular-nums.
- **Row anatomy** (`.se-row`): catdot (8×8 circle colored by category hue, expenses only) · `.se-label` text input · `.se-date` type=date input (expenses only) · `.se-cat` select (expenses only) · `.se-amt` group · `.se-del` trash button. Focus styling: 3px ring of `color-mix(--accent 16%, transparent)` and border `color-mix(--accent 55%, transparent)`.
- **`.se-amt` + `.se-cur` pattern.** `.se-amt` is the bordered container (`background var(--inset)`, 9px radius, width 116). Inside, `.se-cur` is the prefix symbol (mono, `--dim`) and `.se-amt-input` is the actual text input (mono, `tabular-nums`, right-aligned, no border, transparent bg). The input is `type="text"` + `inputMode="numeric"`. **Live raw-string buffer**: `value` reads `r.amt ? shown(r.amt).toLocaleString(cur.locale) : ""` (empty when 0). `onChange` strips non-digits with `replace(/[^\d]/g, '')`, parses int, calls `toBase(n)`. No decimal point, no fractional cents — integers in display units converted back to USD-base.
- **Foot tally** (whole month): `Income − Spending = Left to save`, with savings rate `(surplus/income)*100` rounded; net pill `.se-tally--net` (`.neg` if negative). Week mode tally instead shows `{Wk} spent · Weekly avg · Δ vs avg`.
- **Save / Cancel.** `commit()` strips empty rows (`r.label.trim() || r.amt`), then `onSave(cleaned, keys, viewKey)`. Cancel = `onClose`. Mousedown on backdrop self also closes.
- **Escape behavior.** Double-duty: if `pickerOpen` (month listbox), first Escape closes the picker only; otherwise Escape closes the editor.
- **Month picker** (`.se-monthmenu`): listbox of `.se-mo-opt`s. Active month gets `.on` + a `.se-mo-check` with `SI.check`. Each option: `.se-mo-name` (Month YYYY) + `.se-mo-net` (signed mono `+/−$N`, `.neg` if surplus<0). ### Projection math

```js
window.project = (principal, monthly, annualReturn, months) => {
  const r = annualReturn / 12;
  const pts = [];
  let bal = principal, contrib = principal;
  for (let m = 0; m <= months; m++) {
    if (m > 0) { bal = bal * (1 + r) + monthly; contrib += monthly; }
    pts.push({ m, bal, contrib, growth: Math.max(0, bal - contrib) });
  }
  return pts;
};
```

Compounding is **end-of-month**: the prior balance grows by `r/12` then receives the contribution. `pts[0]` is the starting state (`bal = principal`, `contrib = principal`, `growth = 0`). `pts[months]` is the final state; the chart plots `bal` (top) and `contrib` (band) with the gap representing growth.

- `weekOfDate("YYYY-MM", "YYYY-MM-DD")` → 1-indexed week within the month.

## 12. Decisions journal

### Worked
- **Persist memberships through `StrategieState` (not modal-local).** — Tiles survive reopen and theme swap; commits on Save.
  **Why:** Prototype scoped members to modal lifetime via `window.STRAT.memberships`; in production that loses every edit on close. Routing through `useShelfStorage` keeps the CLAUDE.md rule ("any persisted setting goes through `useShelfStorage`") intact and gives free import/export.
  **Applies to:** `StrategieState.memberships`, `strategieSaveStatement` in `useShelfStorage.ts`, `StatementEditor` props.
  **Date:** 2026-06-03.

- **Extend `onSave` signature with optional 4th arg `memberships`, instead of adding a parallel `onSaveMemberships` callback.** — Single commit path; backward compatible.
  **Why:** Two callbacks would force two separate stores/coalescing; one save event matches the prototype's "Save to dashboard" UX where membership edits are committed atomically with the statement. Making the 4th arg optional keeps existing 3-arg call sites type-clean without a shim.
  **Applies to:** `StatementEditorProps.onSave`, `StrategiePanelProps.onSaveStatement`, `strategieSaveStatement`.
  **Date:** 2026-06-03.

- **Encode the brand color via a `--brand` CSS custom property on the tile, swatch, and preview.** — All tile state (bg, border, hover glow, mono text, focused-swatch ring) derives from one variable.
  **Why:** Prototype already does this and it keeps every per-brand tint in CSS via `color-mix(in srgb, var(--brand) …%, …)` — adding a new color anywhere only sets `--brand`.
